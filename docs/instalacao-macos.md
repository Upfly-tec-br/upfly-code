# Instalar no macOS

macOS 11 ou mais novo. Não pede senha.

1. Baixe o pacote em https://upfly.tec.br:
   - Mac com **Apple Silicon** (M1, M2, M3, M4...): `UpflyCode-macos.zip`
   - Mac com **Intel**: `UpflyCode-macos-intel.zip`
   (Na dúvida, baixe o primeiro: o instalador percebe se é Intel e baixa o certo.)
2. Dê dois cliques no `.zip` para extrair.
3. Na pasta extraída, clique com o **botão direito** em **Instalar Upfly Code.command**
   e escolha **Abrir** (na primeira vez o Mac pede essa confirmação).
4. O Upfly Code abre sozinho. Depois, ele fica no **Launchpad**.

O instalador:
- coloca o aplicativo em `~/Applications/Upfly Code.app`;
- cria o comando `upfly-code` em `~/.local/bin`;
- deixa o português e o chat do Claude instalados.

Problemas? Veja [problemas comuns](problemas-comuns.md).

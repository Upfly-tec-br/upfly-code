# Instalar no Windows

Windows 10 ou 11 (64 bits). Não pede senha de administrador.

1. Baixe `UpflyCode-windows.zip` em https://upfly.tec.br.
2. Clique com o botão direito no arquivo e escolha **Extrair tudo**.
3. Na pasta extraída, dê dois cliques em **Instalar Upfly Code**.
   - Se o Windows mostrar "O Windows protegeu o computador", clique em
     **Mais informações** e depois em **Executar assim mesmo**.
4. O Upfly Code abre sozinho. Depois, ele fica no **Menu Iniciar** e na
   **Área de Trabalho**.

O instalador:
- coloca o aplicativo em `%LOCALAPPDATA%\UpflyCode\app`;
- cria os atalhos e a opção **Abrir no Upfly Code** no botão direito das pastas;
- instala o **Git Bash** portátil se o Git ainda não estiver instalado (o Claude
  precisa dele no Windows) e deixa o terminal usando o Git Bash;
- deixa o português e o chat do Claude instalados.

Problemas? Veja [problemas comuns](problemas-comuns.md).
